# Metrologix EMC (Smart Metrology & Uncertainty Engine)

**Metrologix EMC** — это расширяемая автоматизированная система метрологического обеспечения и расчета бюджетов неопределенности для лабораторий ЭМС в соответствии с требованиями **CISPR 16-4-2** и руководства **ISO/IEC Guide 98-3 (GUM)**.

Приложение позволяет автоматизировать сквозной процесс: от обработки сырых спектральных данных измерительных трактов до генерации кастомизированных файлов коррекции под анализаторы помех и формирования итоговых протоколов неопределенности.

---

## 🛠 Ключевые возможности

- **Task-Oriented Architecture (Ориентация на задачи):** Управление всей измерительной системой из единого файла задачи (`task_config.yaml`). Изменение диапазонов графиков, лимитов, шага точек и состава оборудования происходит без изменения кода.
- **Component-Based Hardware (Автономные плагины):** Каждое устройство (кабель, эквивалент сети, приемник) полностью изолировано в своей папке-пакете. Оно самостоятельно инициализируется, парсит свои данные и рассчитывает собственные метрологические параметры.
- **Умная обработка S-параметров (Тип А):** Автоматическая склейка частотных декад (от 100 кГц до 40 ГГц) сырых CSV-файлов анализатора, расчет коэффициента передачи методом замещения и вычисление стандартного отклонения (СКО) по многократным измерениям.
- **Генерация коррекций под «железо»:** Динамическая адаптация шага точек (логарифмический/линейный) и экспорт сглаженных файлов коррекции по шаблонам конкретных приборов (Keysight, Rohde & Schwarz и др.).
- **Расширенная математика распределений:** Поддержка прямоугольного, U-образного, треугольного, нормального (k=1, k=2) и трапециевидного законов распределения погрешностей.

## 🚀 Порядок работы системы

1. **Инициализация:** Движок читает файл задачи, находит указанные приборы в `src/hardware/` и запускает их внутренние парсеры.
2. **Метрологический расчет:** Приборы обрабатывают свои файлы. Кабель склеивает файлы декад, вычисляет среднее $S_{21}$ и неопределенность типа А. ЭСП подтягивает точки из сертификата калибровки.
3. **Генерация файлов коррекции (Опционально):** Движок прореживает данные кабеля до нужного количества точек, запрашивает у выбранного приемника его внутренний синтаксис (`analyzer_template.py`), форматирует файл и сохраняет в `output/.../hardware_corrections/`.
4. **Визуализация:** Модуль `Visualizer` нарезает графики по указанным поддиапазонам частот, добавляет линии лимитов, затеняет коридоры неопределенности $k=2$ и сохраняет их в `output/.../plots/`.
5. **Суммирование бюджета:** Движок рассчитывает общую инструментальную неопределенность лаборатории ($U_{lab}$) на всей сетке частот метода.

## 📈 Пример конфигурации задачи (`task_config.yaml`)

```yaml
task_name: "Conducted_Emissions_CISPR_16"
target_method: "CISPR 16-4-2 (Conducted)"

hardware_setup:
  receiver: "keysight_n9030b"
  cable_system: "assurance_cable_11m"
  lisn_amn: "schwarzbeck_nslk8127"

hardware_corrections_output:
  generate_corrections: true
  target_instrument_format: "keysight_n9030b"
  devices_to_export:
    assurance_cable_11m:
      export: true
      step_mode: "logspace"
      points_count: 500

plots_output:
  generate_plots: true
  items:
    - device_id: "assurance_cable_11m"
      parameter: "S21"
      show_uncertainty: true
      sub_plots:
        - title: "Cable S21 (Low Frequency Range)"
          freq_min_hz: 150000
          freq_max_hz: 30000000
          x_scale: "log"
          show_limit_line: true
          limit_value_db: -1.5
```
